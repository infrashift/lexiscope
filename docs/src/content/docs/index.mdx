<CardGrid>
	<Card title="Rules in CUE" icon="setting">
		Each ruleset is a CUE file. A user file can add a rule, turn off a rule or change a limit.
		One lexicon holds the approved term for each concept.
	</Card>
	<Card title="Prose and comments" icon="document">
		lexis reads Markdown files. It also reads the comments of Go, Zig, Python, C and Rust files with ztree.
	</Card>
	<Card title="SARIF output" icon="list-format">
		lexis writes SARIF 2.1.0 and 2.2 reports for code scanning tools. It also writes text and JSON.
	</Card>
	<Card title="Strict code rules" icon="approve-check">
		The lexis source follows the NASA Power of 10 rules. Its own documentation follows ASD-STE100.
	</Card>
</CardGrid>
